# E Sports Wagers

A single-file, dependency-free esports match practice app. Browse ranked lobbies, create a match, play a simulated result, and track your practice balance and match history.

## Run the prototype

Open `index.html` directly in a modern browser. The page uses only vanilla HTML, CSS, and JavaScript; no build step, server, external assets, or npm packages are required.

## Try it out

- Filter, search, and sort open matches by game, payout, and start time.
- Make an 18+ self-declaration, join or create a lobby, simulate a challenger and match result, or forfeit an active match.
- Track practice credits, lobby entries and cancellations, wins/losses, activity, win rate, and match history.
- Edit your player name, link or remove practice game profiles, view player rankings, and explore safety details.
- Match, profile, wallet, and activity changes persist in this browser using local storage.

## Prototype limitations

All players, rankings, and game profiles are sample data. Match outcomes are randomly generated locally; no game is launched, observed, or scored. The self-reported 18+ declaration is not age or identity verification. No gaming account is contacted, and practice credits have no cash value. The app does not collect ID documents, accept deposits, or process wagers or payouts. Local state can be cleared by removing this site's browser storage. This is not production-ready for real-money play; any real service would need appropriate legal, privacy, age/identity, security, game-platform, and jurisdictional review.
